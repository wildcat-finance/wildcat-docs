# AGENTS.md — Wildcat Protocol Documentation

This repository contains the source for the **Wildcat Protocol** documentation, published via GitBook at https://docs.wildcat.finance.

## What Wildcat is

Wildcat is a decentralised protocol for **fixed-rate, undercollateralised borrowing and lending** (live on Ethereum mainnet and Plasma). Borrowers deploy permissioned on-chain "markets" with fully customisable terms; lenders deposit ERC-20 assets in exchange for rebasing "market tokens" (debt tokens). The protocol does not assess borrower creditworthiness, custody funds, or insure against default — lenders bear full counterparty risk. The current generation is **V2** (V1 is deprecated).

## Repository conventions

- Docs are **GitBook-synced Markdown**. `SUMMARY.md` is the table of contents, `README.md` is the landing page, and `.gitbook.yaml` (if present) configures the `root` and `structure`.
- Every content page begins with YAML frontmatter containing a one-line `description:`. **Keep this populated** — GitBook's auto-generated `/llms.txt` is built from page titles + these descriptions.
- The published `/llms.txt` and `/llms-full.txt` are generated by GitBook and **cannot be replaced by committing a file** of the same name; improve them by improving titles and `description:` frontmatter. The curated `llms.txt` in this repo is the portable/canonical copy for non-GitBook consumers and for browsing the source.
- `skills/` is intentionally **not** listed in `SUMMARY.md`, so it is not published as a site page; it is a resource for AI tooling.
